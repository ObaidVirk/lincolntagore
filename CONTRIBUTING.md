# Contributing

Thanks for taking the time to contribute.

## Development setup

1. Fork and clone the repository.
2. Create `.env.local` from `.env.example`.
3. Install dependencies with `npm install`.
4. Start the development server with `npm run dev`.

## Before opening a pull request

Run the complete local check:

```bash
npm run check
```

Pull requests should:

- Explain the user-facing or technical change.
- Include screenshots for visual changes.
- Keep secrets and local environment files out of commits.
- Update documentation when setup or behavior changes.
- Keep changes focused and use the existing project patterns.

## Commit and pull request guidance

Use a clear title that describes the change. Keep unrelated refactors out of feature or bug-fix pull requests. Maintainers may request changes before merging.
